-Encriptador de Texto (Desarrollo de Algoritmos)
--------------------------------------------------------------------------------------------------------------------------------------------------------

-Año: 2024
--------------------------------------------------------------------------------------------------------------------------------------------------------
-Objetivo/Descripción: 
--------------------------------------------------------------------------------------------------------------------------------------------------------
Creación de un software para encriptar y desencriptar mensajes de texto, centrado en el desarrollo y aplicación de algoritmos de cifrado.

-Lenguajes de programación: 
--------------------------------------------------------------------------------------------------------------------------------------------------------
Java, HTML, CSS.

-Metodología seguida: 
--------------------------------------------------------------------------------------------------------------------------------------------------------
Desarrollo de algoritmos de cifrado en Java. Procesamiento de texto de entrada. Validación funcional de los procesos de encriptación y desencriptación.

-Resultados: 
--------------------------------------------------------------------------------------------------------------------------------------------------------
Desarrollo de una aplicación funcional que recibe, procesa y transforma texto, demostrando competencia en lógica de programación front-end y back-end.
